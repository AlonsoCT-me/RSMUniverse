# Matriz de transferencia a Shopify Prestige

Orden obligatorio: configuración nativa → componentes existentes → extensión mínima → nueva sección rsm-* solo ante brecha demostrada. La existencia de una sección/schema se verifica en [PRESTIGE_AUDIT](PRESTIGE_AUDIT.md). Las recomendaciones de composición siguientes **no certifican una equivalencia visual ni autorización de implementación**. Nunca reemplazar el motor de carrito, variantes, filtros o galería.

La propuesta puede combinar varias secciones nativas para una región React; no se deduce que todo requiera Liquid nuevo. Ver [SECTION_CONTRACTS](SECTION_CONTRACTS.md) para contratos condicionales.

## Componentes transversales

| React | Shopify real inspeccionado | Brecha/decisión |
|---|---|---|
| Header | sections/header.liquid, header-group.json; assets/rsm-header.css ya existe | Preservar trabajo local Dark Liquid Glass; no sustituirlo al trasladar prototipo; revisión independiente. |
| Newsletter/Footer | sections/newsletter.liquid + footer.liquid y footer-group.json | Form real y menús/policies traducibles; omitir enlaces internos del prototipo en storefront. |
| ProductCard | snippets/product-card.liquid + price-list, option-value + product-form/quick-buy-modal | Layout inferior, campo modelo y bolsa+ requieren análisis de integración sin Core; no duplicar compra. |
| CartDrawer | sections/cart-drawer.liquid + line-item y assets/theme.js | Conservar eventos, errores/stock/loading y foco nativos. |
| Accordion | snippets/accordion.liquid, faq y bloque accordion en product-info | Configurar contenido, color y presentación; no portar useState. |
| Reveal | reveal_on_scroll en schemas existentes | Preferir comportamiento nativo; respetar reduced motion y editor. |
| ImagePlaceholder | imágenes oficiales/configurables | No migrar como fotografía ni como claim de catálogo. |

Si la fidelidad de ProductCard exige mover markup del snippet Core y no hay punto de extensión, detener la implementación de esa brecha, describir diff mínimo/impacto y solicitar autorización. Esta documentación no autoriza cambios al Core ni loaders globales.
