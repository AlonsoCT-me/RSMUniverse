# RSM Universe — eCommerce Prototype

Prototipo visual y funcional del eCommerce de Rancho San Marco (RSM Universe), desarrollado como herramienta de consulta, validación de diseño y experiencia de usuario.

## Propósito

Este proyecto tiene como objetivo facilitar la revisión y aprobación de la propuesta visual del sitio web, así como establecer una referencia para su posterior adaptación e implementación en Shopify, utilizando el tema Prestige de Maestrooo.

## Alcance

- Validación de diseño y experiencia de usuario (UX/UI).
- Revisión de componentes y comportamiento responsive.
- Demostración de navegación e interacciones.
- Referencia visual y funcional para la implementación en Shopify.

## Prototipo en línea

[Consultar RSM Universe](https://alonsoct-me.github.io/RSMUniverse/)

## Tecnologías

- React
- TypeScript
- Vite
- SCSS
- GitHub Pages

## Consideraciones

Este proyecto es exclusivamente un prototipo de prueba y consulta. No constituye una tienda en producción ni procesa transacciones comerciales reales.

Los productos, precios, imágenes, contenidos e interacciones pueden estar sujetos a modificaciones y aprobación por parte de RSM Universe.

La implementación definitiva se realizará en Shopify, aprovechando las funcionalidades nativas y las posibilidades de personalización del tema Prestige.
